# 功能范围

[English · 详细清单](PARITY.en.md)

Grox 的桌面核心覆盖助理与频道、接入模型、流式对话、审批与提问、会话文件、工作台和失败恢复。初次使用可运行内置演示，也可选择已配置的真实 CLI 或 API。演示使用预设回复。

| 功能 | 使用条件 |
| --- | --- |
| 真实引擎 | 安装并登录对应 CLI，或配置 API 端点、模型与凭据。 |
| 浏览器与电脑工具 | 本机需要受支持的浏览器或系统权限。SSH 操作需要可连接的主机和经过验证的主机公钥。 |
| 手机端 | 桌面应用需运行，手机在同一局域网，可读取与发送会话。 |
| Composio 与自定义 MCP | 需要可用的第三方账户或端点。工具可用性取决于引擎与审批模式。 |
| 定时任务、Webhook、自动化 API | 由本机 Grox 进程提供服务。API 和 Webhook 监听回环地址。 |
| 语音 | 依赖系统语音、麦克风权限及 WebView 能力。 |
| 团队交换 | 处理个人工作区的兼容数据。导入时提供跳过项，定时任务、技能和连接待用户启用。 |

当前没有代管云电脑、跨设备云同步、团队计费或组织权限管理。验证环境与详细支持范围见英文清单。
