# MCP 服务器

[English](MCP.en.md)

在「设置 → MCP 服务器」添加 Streamable HTTP 端点或本地 stdio 命令。可应用于所有助理或指定助理。每次 CLI 运行时，Grox 为所选 CLI 写入临时配置。本地命令由 CLI 启动，请先核对命令和参数。

HTTP 配置支持 Bearer 令牌、额外请求头，以及客户端凭据、刷新令牌和授权码加 PKCE 的 OAuth。密钥和请求头值存放于本机的 `secrets.json`。工作区和界面只记录配置状态与请求头名称。编辑时可留空以保留现有令牌。

使用 OAuth 授权码时，配置授权地址、令牌地址和客户端 ID，再选择「在浏览器中授权」。Grox 使用临时本机回环回调，授权结果会在浏览器中显示。外部服务器由相应 CLI 访问。Grox 内置电脑、浏览器及应用工具通过单独的每轮网关提供。
