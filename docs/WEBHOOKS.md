# 入站 Webhook

[English · 签名与请求示例](WEBHOOKS.en.md)

从「定时任务 → Webhook」为助理创建触发器。Grox 提供带私有令牌的本机地址，只在回环接口接收请求。发送 JSON 或纯文本后，工作区会生成一条任务会话。可在触发器中写提示词说明怎样使用收到的正文。

可要求 HMAC 签名，将 URL 中的令牌用作密钥，并根据英文详细规范发送 `X-Grox-Timestamp` 和 `X-Grox-Signature`。请像密码一样保存完整链接。停用触发器后链接仍在，但请求会被拒绝。删除后令牌失效。

界面会列出最近投递。保留了请求正文的投递可手动重放，重放会建立新任务。具体签名格式、请求 ID、载荷与请求示例见[技术细节](WEBHOOKS.en.md)。
